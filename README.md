# Проект "Создание классов"

## Описание:

Проект "Создание классов" - это выполненное задание по обучению, где мы учимся создавать классы в Python. Конкретно в данном примере мы создали классы, отвечающие за сохраниние количества и наименования товаров электроники. 

## Установка:

1. Запустите PyCharm на вашем компьютере
2. Клонируйте репозиторий:
```
https://github.com/korklin/Project2.git
```
3. В главном меню PyCharm перейдите в меню Get from VCS. Вставьте ссылку на репозиторий и нажмите на кнопку Clone.

## Содержание проекта:

Модули  директории src содержат два класса, отвечающие заданию: Product и Category.
В классе Product определены следующие свойства:
- название (name),
- описание (description),
- цена (price),
- количество в наличии (quantity).
В классе Category определены следующие свойства:
- название (name),
- описание (description),
- список товаров категории (products), который является результатом работы класса Product.
Модули test_category.py и test_product.py содержит в себе тесты для описанных классов, включающие в себя:
- проверку, что все продукты в категориях являются экземплярами Product, и что это именно те объекты, которые были переданы при создании,
- проверку корректности сохранения полей объектов Product после инициализации,
- проверку, что категории создаются с правильными полями и нужным количеством продуктов,
- проверку, что попытка создать категорию с аргументом products, не являющимся списком, вызывает исключение TypeError,
- тестирование корректности накопления значений счётчиков категорий и продуктов при множественном создании объектов,
- проверку, что один и тот же продукт можно добавить в категорию несколько раз, и он действительно будет продублирован в списке.
